# gta6-midia

Robô que baixa os vídeos oficiais do GTA VI do canal da Rockstar Games e publica cada um como arquivo com link público, para o invideo importar.

- Lista do que baixar: `videos.txt`. Acrescente uma linha e faça commit: o robô roda sozinho.
- Resultado da última execução: `status.md`.
- Arquivos: aba **Releases**, release `midia`. Link de cada um: `https://github.com/dalprasystems-softwarehouse/gta6-midia/releases/download/midia/<nome>.mp4`
